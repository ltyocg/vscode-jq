# jq 格式化风格规范

本文是格式化器的规范基准（normative spec）。格式化器保留 token 文本，
只改空白与按 R3 策略增删的对象尾随逗号。所有规则由 AST 结构
驱动（见 `parser/`），与源码写法相关的决策只有两类：作者的展开/断行意图
（保留），与行宽（`printWidth`，默认 100）。

## 缩进模型（home）

每个构造有一个「home」＝它作为内容出现的层级，是它自身的括号组与
+1 层子内容的锚点。**行中构造的 home 由引入它的前缀决定**，行首构造
的 home＝所在行的缩进：

- `|` / 运算符之后的内容：链 cont＋1 层；
- 悬挂组首元素：元素列（开括号列＋2）；
- `key: ` 的值、`;` 之后的查询：条目层级（前缀不开新层）；
- 子句关键字体、def 体、reduce/foreach 源与模式：关键字 home＋1 层。

构造自身的括号组以它的 home 为基础缩进（元素在 home＋1 层、闭括号
回 home）。悬挂组的纵向对齐（元素列＝开括号列＋2、链对齐开括号列、
子句关键字对齐 if/try 列）是列锚点，独立于本模型。

## 作者折行（普遍规则）

**凡本风格可以断行的边界，源码有换行即保留**，并归一化到本风格的
断行形态（行首运算符、尾随分隔符）与缩进规则。可以断行的边界＝语法
结构的子节点之间，包括但不限于：

- 链的运算符两侧（管道与双目运算符，尾随风格归一化为行首）；
- 括号组的元素边界（开括号→首元素、元素/分隔符之间、末元素→闭括号
  ——开括号后断行走分隔展开，其余位置断行且首元素在开括号行上则保持
  悬挂形态）；
- if/try 的子句关键字两侧与体之前；
- def 前后、def 参数边界、def 冒号之后；
- as / label / reduce / foreach 的各段之间（head 与 `as`、`as` 与
  模式、`?//` 备选之间、模式与 `|`/分组开括号之间、关键字与源表达式
  之间）；
- 对象冒号之后；
- 逗号/分号分隔符两侧；断行的逗号条目比逗号链深一层（纵向列表缩进
  一级），条目内部的链随条目层。

**不可断行的原子结构**（其内部的换行折叠）：后缀链（`.a.b[0][]?`）、
函数名与实参开括号（`map(`）、格式与字符串（`@base64 "x"`）、一元
符号与操作数。

## 规则

### R1 链：行首运算符

管道与全部双目运算符（含关键字 `and`/`or`）统称链。链断行时运算符提到
下一行行首，与链的起始行同层：

```
users
| map(select(.age > 18))
| group_by(.city)
```

断行判定（逐链接贪心）：

- 作者在操作数之间断过行（运算符前后任一侧有换行即算；仅一侧断行——
  含尾随风格——归一化为行首运算符、操作数跟上；**前后都断行**时运算符
  独占一行，操作数另起一行，比链 cont 深一层）；
- 或贪心超宽（**首行贪心**）：`op` 加操作数**首行**（到操作数内第一处
  源码断点为止的平铺宽度）放不进剩余行宽。操作数内无断点时即整段
  平铺；结构性多行的操作数只量首行 —— 运算符行内放得下就保持行内、
  让多行结构自己展开（jqjq 语料 `|= map(` 的形态），不因整段平铺
  放不下而强制下沉。

不断行时全部平铺在一行。一元负号永不断点。链的续行缩进：链起始 token
所在行的缩进；当链以子句/键前缀开始（`if `、`then `、`key: `、`def f: `
等，即起始行在操作数之前已有内容）时，取该行缩进 +1 层。操作数是
`op ` 之后的内容：home 与其内部链的 cont 都是链 cont＋1 层（`| eval_ast(`
的实参锚在段 home，不退回 '|' 所在行）。

### R2 组：单行、悬挂或分隔展开

`(...)`、`[...]`、`{...}`（含调用实参、reduce/foreach 分组）按作者意图
三选一。判定的输入：

1. 组**自身**的元素边界处有源码换行（开括号→首元素、元素之间、末元素
   →闭括号；嵌套子组内部的换行不算，各组独立判断）；
2. 组自身层级有注释（不在任何子节点 span 内的注释 token）；
3. 任一元素「结构性多行」（见下）；
4. 平铺渲染超宽（当前列 + 平铺宽度 > `printWidth`，仅位置相关）。

- **单行**：无作者断行/注释、元素非结构性多行，且平铺不超宽。内侧不
  补空格（`map(.a)`、`{a: 1}`）。
- **悬挂**：作者把首元素写在开括号行上（开括号→首元素未断行），且组
  内另有作者结构（其余边界断行、注释或结构性多行元素）—— 保留这个
  形态：首元素留在开括号行，**后续元素竖向对齐到首元素所在列**（开
  括号列 +2，按作者断行或超宽补断另起一行，尾随分隔符）；闭括号回
  **开括号列**（调用式开括号 `'f('` 例外，回开括号所在行的行首），
  作者未断行时贴末元素行。**注释收尾的前导分隔符**：元素与分隔符
  之间有注释（行尾或独立）时分隔符无法尾随，由它承接断行、前导
  下一元素行 —— 行尾注释时对齐开括号列，独立注释留在自然位置、
  分隔符与元素随其后（`, env: …` 的作者形态）。**内侧补位**：与
  内容同行的开括号之后、闭括号之前各恰好一个空格：

  ```
  [ 1, 2,
    3 ]
  ( "aaa"
  + "bbb"
  )
  | { "n": "\n",
      "r": "\r"
  ```

  悬挂首元素的链对齐**开括号列**（行中开括号——如 `'| ('`、`'f( ('` 之后
  ——时 ≠ 行缩进；链若取行缩进会与外层链同列、层级消失）。

- **分隔展开**：作者在开括号之后断行，或仅因超宽被迫展开 —— 开括号
  留在当前行尾，每元素独占一行（基础缩进 +1 层，尾随 `,`/`;`；末元素
  之后的尾随逗号按 R3 的尾随逗号策略处理），闭括号回基础缩进。组的基础缩进＝拥有它的构造的
  home（开括号起行时二者相等；行中开括号时锚到构造 home 而非所在
  行）。元素是组的「段」：home＝基础缩进＋1 层，链对齐基础缩进
  （jqjq 语料 `_suffix` 的 `//` 交替链形态）。

空组输出 `[]`/`{}`（内含注释除外）。

**唯一实参拥抱**：调用实参组只有一个实参且该实参是裸的对象/数组词项
（无后缀链）时，实参组自身不展开 —— 开/闭括号贴着实参，实参按自己的
规则展开（作者在实参组自身层级断行时不拥抱，按展开处理）：

```
map({
  b: 1
})
```

「结构性多行」＝与位置无关必然多行：悬挂/展开的子组、作者断行的链、
按 R4/R5 展开的 if/try、def。

### R3 对象条目

放得下则 `key: value` 一行，值起始留在键行 `: ` 之后，值的续行随条目
home（未断行时 `key: ` 不开新层）；作者在冒号之后断行时保留该断行，
值另起一行（条目 home＋1 层，续行随该层 —— jqjq 语料 39 处冒号断行
全部如此）。`{$var}`、`{foo}`、`{(expr): v}`、关键字键（`{if: 1}`）按
token 原样输出。析构模式条目同形（冒号断行保留）。

**尾随逗号策略**（`trailingComma` 选项）：对象构造是 jq 语法中尾随逗号
唯一合法的位置（数组、函数实参、解构模式都不允许），策略只作用于
对象组的末条目：

- `'never'`（默认）：一律去掉，输出中不出现对象尾随逗号；
- `'multiline'`：展开形态（悬挂/分隔展开）在末条目后补齐尾随逗号
  （这是格式化器唯一允许新增 token 的位置），单行形态去掉；
- `'preserve'`：保留源码中逗号的有无，不锁定逗号周围的空白。

末条目与闭括号之间的注释不受策略影响：去掉逗号时注释原位保留，
补齐时逗号紧贴末条目、位于注释之前。单行测量不计将移除的逗号，
规则也适用于外层平铺输出的内嵌对象。

### R4 if/elif/else/end

整体放得下则一行。子句关键字（`then`/`elif`/`else`/`end`）只在作者
断行或关键字自身放不下时换行——分支内容多行或超宽不会把关键字挤下
去。**子句锚点取 `if` 关键字所在列**（if 起行时即行缩进；if 处于悬挂
组首元素或 `'| '`、`'key: '` 等行中前缀之后时，子句关键字与 if 竖向
对齐）。条件与分支体放在关键字行（放得下且非结构性多行时），否则
下一行 +1 层。

### R5 try/catch

`try <body> catch <handler>`；`catch` 只在作者断行或自身放不下时换行，
与 **`try` 关键字所在列**对齐（同 R4 的列锚点）；body/handler 放不下
或结构性多行则下一行（比 try 深一层）。

### R6 as 绑定与 reduce/foreach

`E as $p ?// $q |`：`E` 按 R1 折行；各段断点（head 与 `as`、`as` 与
模式、`?//` 备选、模式与 `|`）按「作者折行」普遍规则处理，断行处取
as 行缩进 +1 层（`|` 归一化到 cont）。模式是 `as ` 之后的内容：
home＝as 层级＋1 层。reduce/foreach 同理（模式 home＝关键字
home＋1 层），另含关键字→源表达式、模式→分组两处；分组是关键字自身
的组：基础缩进＝关键字 home（`(` 起行时为其行缩进，即 home＋1 层）。
label 的 `$out |` 与 as 的 `|` 同形处理。

### R7 def

def 前后的断行按「作者折行」普遍规则处理：源码在 def 之前、def 的 `;`
之后断行才换行（`( def …` 的悬挂形态由此保留；紧跟 `|` 的例外见 R1 ——
管道归一化后 def 与 `|` 同行，不再二次断行）。def 的 home＝所在条目
层级（`|` 之后的段内为 cont＋1 层）；体放不下时另起一行（def
home＋1 层），续行随该层；参数列表是 def 自身的组：基础缩进＝def
home。`def` 可以出现在任何查询位置（管道段、括号内、子句体）。

### R8 label/break

`label $out | <body>`，管道按 R1；`break $out` 原子。

### R9 后缀链

`.foo[0][]?`、`."str"`、`f(...)` 的后缀序列对宽度是原子，内部无断点；
仅调用的实参组可按 R2 展开。

### R10 注释

独立注释独占一行，取下一 token 上下文的缩进，前后空行按源码保留；行尾
注释留在行尾，与代码的源码间距保留（至少 1 空格），其后强制换行；反斜杠
续行注释原样保留（含保护性尾空格）。

### R11 空行

源码有空行则保留（连续多个压缩到两个），绝不凭空增加。

### R12 语义守护（非风格）

`.` 与关键字字段名之间的源码邻接保留 —— `.catch`（字段访问）与
`. catch`（身份 + 子句关键字）语义不同，任一方向的归一化都会改写程序。
字符串字面量（含插值与裸换行）、数字等 token 文本一律原样。

### R13 输出封套

结构换行使用源码第一个 token 外的换行符（没有则用 LF）。字符串和注释续行
内部的换行原样保留；注释末尾的换行不属于注释正文。输出以单个结构换行
结尾；末尾空行修掉；空、纯空白和纯注释输入原样返回。

## 错误处理

输入必须是语法合法的 jq（词法或解析错误抛 `FormatError`，扩展入口据此
拒绝改动文件）。括号不平衡以解析错误呈现。
